# 第一部分：外科（痈疽辨证论治）

## 一、痈疽阴阳总辨（辨证第一关口）

| 维度 | 阳证 | 阴证 |
|---|---|---|
| 形 | 高突而肿起 | 低平而陷下 |
| 色 | 纯红 | 带黑 |
| 初起 | 必痛 | 必痒 |
| 溃烂 | 多脓 | 多血 |
| 收口 | 身必轻爽 | 身必沉重 |

**生死铁律**: 先阴而变阳者生，先阳而变阴者死。
**治法总纲**: 阳毒可用攻毒之剂，阴毒须用补正之味。
**阶段转换**: 痈疽未溃之前以化毒为先，既溃之后以补正为急。溃后"即有余毒未尽，不必败毒"。
**警语**: 痈疽等毒必先辨阴阳——"外大如豆，内大如拳；外大如拳，内大如盘"，救痈如救火宜一时扑灭。

## 二、背痈（代表病种，治法最全）

### 1. 急消汤（背痈阳证初起）
- **组成**: 忍冬藤2两、紫花地丁1两、天花粉3钱、桔梗3钱、青蒿3钱、甘草3钱、茜草3钱、甘菊花3钱、贝母2钱、黄柏1钱
- **煎服法**: 水煎服。一剂轻，二剂又轻，三剂全消。
- **方义**: 消阳毒之初起最神，既无迅烈之虞又有和解之妙。**孟浪用虎狼之药虽毒消散而真元耗损，往往变成别病。**

### 2. 神散阳痈汤（阳痈亦效）
- **组成**: 车前子5钱、贯众5钱、甘草5钱、天花粉5钱、赤茯苓5钱、生地1两、柴胡1钱、羌活2钱、黄芩3钱、紫菀3钱
- 一剂消大半，二剂全消。

### 3. 变阳汤（背痈阴证初起——大补化阴为阳）
- **组成**: 金银花8两、人参2两、黄芪2两、附子1钱、黑荆芥2钱、天花粉5钱、甘草5钱、白芍1两、柴胡2钱
- **煎服法**: 水十碗煎汁二碗，先服一碗少缓再服一碗。服后阴必变阳而作痛；再一剂痛亦消；再一剂痊愈。
- **方义**: 阴痈必正气大虚邪得而入——大用补气补血佐散郁散毒。金银花性补善解阴毒，附子直入阴毒之中；**世人往往失补，至溃烂如碗大而不可收拾。**

### 4. 转败汤（背痈溃烂洞见肺腑·阴虚不能变阳）
- **组成**: 茯苓2钱、熟地4两、人参4两、金银花4两、白术4两、肉桂3钱、远志3钱、黄芪2两、麦冬2两、当归1两、山茱萸2两、五味子1钱
- **煎服法**: 水煎服。一剂胃气大开者即可转败为功。
- **方义**: 补气血更补肺肾之阴（阴生则阳长），金银花解余毒，毒散血生肉长皮合。

### 5. 生肤散（疮口不收·阴虚不能济阳）
- **组成**: 人参5钱、焦白术5钱、熟地2两、肉桂1钱、忍冬藤1两、麦冬1两、当归1两、山茱萸1两
- **煎服法**: 水煎服。二剂肉长，又二剂疮口平，又二剂痊愈。
- **方义**: **脓尽则毒化矣，疮口不收乃阴气之虚**——独阴不长独阳亦不生，大补其阴使阴精盛满自能灌注疮口，不用生肌外敷药而肉内生。

### 6. 收肌饮（疮口不收亦效）
- **组成**: 白术2两、熟地2两、人参1两、山茱萸1两、麦冬1两、当归1两、甘草3钱、肉桂2钱、菊花3钱、天花粉3钱（切戒房事一月）

### 7. 定变回生汤（背痈长肉后开裂流水·色欲恼怒不谨）
- **组成**: 人参4两、黄芪3两、山茱萸1两、茯苓1两、忍冬藤2两、麦冬2两、白术2两、当归2两、五味子3钱、肉桂2钱
- **方义**: 疮痈最忌房事，其次恼怒。犯恼怒新肉开裂，犯房事必致死亡。急补气血万不可仍治其毒。

### 8. 助阳消毒汤（夏月背痈疮口不起·脉大无力·阴证似阳）
- **组成**: 人参8两、黄芪1斤、当归4两、白术4两、附子5钱、陈皮5钱（水煎成膏分两次服）
- **方义**: 疮口不起者乃阴证——发热作渴是水不足济火。**阴寒之气甚盛而微阳之力不能胜，非附子辛热斩关入阵不能涤荡阴邪。** "舍痈从症，实治痈之变法。"

### 9. 十全大补汤大剂方（痈疽溃后全补）
- **组成**: 人参1两、当归1两、黄芪2两、熟地2两、白芍5钱、茯苓5钱、白术5钱、肉桂2钱、川芎3钱、甘草3钱
- **方义**: 溃后当全补不宜偏补；多其分两大剂煎服始克有应验。

## 三、肺痈论要点

- **治法原则**: 肺痈未溃当消痈解毒，既溃当补肺托脓。
- 方用完肺汤、肺痈救溃汤、养肺去痿汤、扶桑清肺汤等（均以补肺阴+解毒排脓为主，详见原书）。

## 四、乳痈论要点

- **乳痈（吹乳/乳岩）辨证**: 未溃以疏肝理气、清热解毒为主（和乳汤等）；溃后以补气血托毒。
- **乳岩（岩）**: 化岩汤——大补气血佐以解郁散结。傅氏强调情志郁怒与乳疾关系。

## 五、外科通用原则（辨证必查）

1. 痈疽必先辨阴阳（形/色/痛痒/脓血/收口五维）
2. 先阴变阳者生，先阳变阴者死
3. 未溃化毒，既溃补正；溃后有余毒不必败毒
4. 疮口不收 = 阴虚不能济阳（非余毒未尽）
5. 阳毒可攻，阴毒须补；阴证似阳者重用参芪附子
6. 疮痈最忌房事与恼怒
7. 溃后补剂必须大剂重投，寻常小剂不济事

# 第二部分：儿科

## 一、儿科辨证特色（傅氏独家）

### 1. 望色（山根）速诊
| 山根色/筋 | 辨证 | 参考方药 |
|---|---|---|
| 色红 / 红筋横直 | 心热 | 前方加黄连麦冬 |
| 色紫 | 心热甚而肺亦热 | 加桑白皮天花粉 |
| 色青 / 青筋直 | 肝有风（直者风上行） | 柴胡半夏白芍茯苓当归白术山楂甘草 |
| 青筋横 | 肝热（风下行） | 茯苓山楂甘草 |
| 色黑 | 风甚而肾中有寒 | 温肾 |
| 色白 | 肺中有痰 | 化痰 |
| 色黄 | 脾胃虚而作泻 | 白术茯苓陈皮人参麦芽神曲淡竹叶 |

### 2. 小儿脉简（不必过谈）
数甚则热，不数则寒；数中浮者风、沉者寒、缓者湿、涩者邪、滑者痰、有止歇者痛。

### 3. 三关望诊
虎口风、气、命三关：紫属热、红属寒、青属惊风、白属疮。风关轻、气关重、至命关难治。

## 二、儿科要方

### 1. 清火散风汤（惊风·内热生风）
- **组成**: 白术3分、栀子3分、茯苓2钱、陈皮1分、甘草1分、半夏1分、白芍1钱、柴胡5分
- **方义**: **小儿纯阳之体，不当有风而状有风者——内出之风非外来之风。内风作外风治是速之死也。** 健脾平肝圣药，断不可以风药表散。

### 2. 压风汤（气虚惊风）
- **组成**: 人参3分、白术3分、神曲5分、甘草1分、半夏3分、丹砂3分、茯神1钱、砂仁1粒、陈皮1分（慢惊加黄芪）

### 3. 万全汤（小儿发热）
- **组成**: 柴胡3分、白术3分、黄芩3分、神曲3分、白芍1钱、麦冬1钱、当归5分、茯苓2钱、甘草1钱、苏叶1钱、山楂3个
- **加减**: 冬加麻黄1分、夏加石膏3分、春加青蒿3分、秋加桔梗3分；有食加枳壳3分；有痰加白芥子3分；吐加白蔻1粒；泻加猪苓1钱。
- **方义**: 小儿诸证不过如此，不可作惊风治之。

### 4. 感冒风寒方
- **组成**: 柴胡5分、白术3分、白芍1钱、茯苓3分、半夏3分、陈皮2分、炙甘草4分、当归8分，水煎热服。

### 5. 泻火止泻汤（小儿热泻）
- **组成**: 车前子2钱、茯苓1钱、白芍1钱、麦芽1钱、黄连3分、猪苓3分、泽泻5分、枳壳2分
- **主治**: 泄泻身热如火、口渴舌燥、喜冷饮不喜热汤

### 6. 散寒止泻汤（小儿寒泻）
- **组成**: 人参1钱、白术1钱、茯苓2钱、肉桂2分、干姜2分、甘草1分、砂仁1粒、神曲5分
- **主治**: 腹痛喜手按摩、口不渴舌滑、喜热饮不喜冷水

### 7. 止吐速效汤
- **组成**: 人参1钱、白术1钱、砂仁1粒、茯苓2钱、陈皮2分、半夏1分、干姜1分、麦芽5分、山楂3个

### 8. 小儿疳证方（心脾两清）
- **组成**: 芦荟1钱、桑白皮1钱、半夏3分、黄连3分、薄荷3分、茯苓2钱、甘草1分
- **方义**: 热而因乎心热、口中流涎——平心火则脾火不旺。

### 9. 小儿咳嗽方
- **组成**: 苏叶5分、桔梗1钱、甘草1钱，水煎热服（有痰加白芥子5分）。

### 10. 小儿疟疾方
- **组成**: 柴胡6分、白术1钱、茯苓1钱、归身1钱、白芍钱半、半夏5分、青皮5分、厚朴5分（水煎露一宿再温服）
- **加减**: 热多加人参黄芪各5分；寒多加干姜3分；痰多加白芥子1钱；夜热加何首乌熟地各2钱；腹痛加槟榔3分。

## 三、儿科铁律

1. **惊则有之，风则无**——小儿惊风是内热生风，禁风药表散
2. 发热不可作惊风治（万全汤统治）
3. 小儿药量极轻（分/钱级），辨证靠望色+脉数简法
4. 山根望诊 + 三关望诊为速诊核心
