## 一、辨证四层递进（强制顺序）

### 第1层：辨真假（寒热真假辨）

| 证 | 核心鉴别要点（原文） | 治法原则 |
|---|---|---|
| 真热 | 口干极而呼水；舌燥极而开裂生刺；喉痛日夜不已；大热烙手而无汗 | 直折其热（三黄石膏类） |
| 真寒 | 手足寒久而不回；色变青紫；身战不已；口噤 | 大剂回阳（参附桂姜） |
| 假热 | 口虽渴而不甚；舌虽干而不燥；即燥而无芒刺纹裂 | 不轻投寒凉，求本 |
| 假寒 | 手足冰冷而有时温和；厥逆身战未太甚而有时安、有时搐 | 不轻投热药，求本 |
| 真热假寒 | 身外冰冷、身内火炽、发寒发热、战栗不已 | 从内治之（三黄汤加石膏生姜乘热饮，井水扑心） |
| 真寒假热 | 下部冰冷、上部大热；渴欲饮水、下喉即吐 | 八味汤大剂探冷与服；擦足心；吴茱萸附子贴足心 |
| 上热下寒 | 上焦火盛吐痰如涌泉、面赤喉痛、上身不欲盖衣、下身冰冷 | 上病下治（附子熟地山茱萸大剂冷服） |
| 火极似水 | 黑带（如黑豆汁）：腹痛、小便如刀刺、面红、热渴饮冷 | 泻火为主（利火汤） |
| 寒极似火 | 假热气喘吐痰：下元寒极逼火上行 | 急补肾水与命门之火（熟地四两+桂附，冷服） |

### 第2层：辨虚实寒热（傅氏鉴别要点速查）

| 鉴别维度 | 实证 | 虚证 |
|---|---|---|
| 疼痛 | 按之愈痛（瘀/食/火结） | 按之即止（血虚/气虚） |
| 月经先期 | 量多 = 火旺水有余 | 量少 = 火旺水不足 |
| 月经后期 | 量多 = 血寒有余 | 量少 = 血寒不足 |
| 经水过多 | 貌似血旺 → 实为血虚不归经（行后复行、困乏） | — |
| 经水早断 | 貌似血枯 → 实为心肝脾气郁 | — |
| 昼夜节律 | 日重夜轻 = 气分/阳虚 | 夜重日轻 = 血分/阴虚 |
| 著衣 | 著单衣怕热 = 劳证骨蒸（忌温补用清补） | 著复衣怕冷 = 虚损（可温补） |
| 痢疾 | 血色鲜红 = 火邪 | 血色紫暗 = 内伤 |
| 痈疽 | 高突/纯红/痛/多脓/收口身轻爽 | 低平/带黑/痒/多血/收口身沉重 |

## 二、傅氏治法金句（辨证依据）

- "止崩之药不可独用，必须于补阴之中行止崩之法"
- "此所以不先补血而先补气也"（血崩昏暗）
- "平肝正所以扶脾"（赤带）
- "治血则湿亦除"（赤带）
- "补后天之脾，正所以补先天之肾"（安奠二天汤）
- "子病治母"（温土毓麟汤：补命门心包之火以生脾胃）
- "治病必求其本，本固则标自立"（小产血崩）
- "急则治其标"（跌闪血崩）
- "虚则逆，旺则顺，是补即转也"（产后转气汤）
- "补气以生血，尤易于补血以生血"（正产血晕）
- "血逢寒则凝，逢散则归经"（血不归经）
- "少火生气，壮火食气"（多怒堕胎）
- "肝木之火旺，乃假象而非真旺"（产后四肢浮肿）
- "小儿纯阳之体，不当有风而状有风者……内出之风"（惊风）
- "先阴而变阳者生，先阳而变阴者死"（痈疽）
- "脓尽则毒化矣，疮口不收乃阴气之虚"（背痈）
- "胃之虚寒责之心，脾之虚寒责之肾"（脾胃证辨）

## 三、产后用药十误（禁忌清单，辨证时必须检查）

1. 因气不舒误用耗气顺气药 → 反增饱闷（禁枳实、厚朴）
2. 因伤气误用消导 → 反损胃气至绝谷（禁枳壳、大黄、三棱、莪术、神曲、厚朴）
3. 因身热误用寒凉 → 必损胃增热（禁芩、连、栀、柏、升、柴）
4. 日内未曾服生化汤，勿用参、芪、术 → 块痛不消
5. 毋用地黄以滞恶露
6. 毋用枳壳、牛膝、枳实以消块
7. 便秘毋用大黄、芒硝
8. 毋用苏木、三棱、莪术以行块；芍药能伐气不可用
9. 毋用山楂汤以攻块定痛而反损新血
10. 毋轻服济坤丹以下胎、下胞

**产后总原则**: "凡病起于血气之衰，脾胃之虚，而产后尤甚……产后必大补气血为先，虽有他症，以末治之。" / "热不可用芩连，寒不可用桂附。" / "大抵新产后先问恶露如何？块痛未除，不可遽加参术；腹中痛止，补中益气无疑。" / "产后先宜补血，次补气，偏补非善。"

## 四、儿科辨证速查（山根望诊）

| 山根色/筋 | 辨证 | 参考方 |
|---|---|---|
| 色红 / 红筋横直 | 心热 | 清心加减（前方加黄连麦冬） |
| 色紫 | 心热甚而肺亦热 | 加桑白皮、天花粉 |
| 色青 / 青筋直 | 肝有风（直者风上行） | 柴胡白芍茯苓当归白术类 |
| 青筋横 | 肝热（风下行） | 茯苓山楂甘草类 |
| 色黑 | 风甚而肾中有寒 | 温肾 |
| 色白 | 肺中有痰 | 化痰 |
| 色黄 | 脾胃虚而作泻 | 健脾（白术茯苓陈皮人参麦芽神曲） |

**小儿脉简**: 但看数不数——数甚则热，不数则寒；数中浮者风、沉者寒、缓者湿、涩者邪、滑者痰、有止歇者痛。

**惊风铁律**: 小儿惊则有之，风则无。纯阳之体内热生风，**断不可以风药表散**，用清火散风汤（白术栀子茯苓陈皮甘草半夏白芍柴胡）健脾平肝。
